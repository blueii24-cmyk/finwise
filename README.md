# FinWise

FinWise is a student-focused personal finance website for tracking income and
expenses, planning a monthly budget, and working toward savings goals.

## Live website

Visit the deployed site at
[blueii24-cmyk.github.io/finwise](https://blueii24-cmyk.github.io/finwise/).

## Included pages

- Home
- About
- Features
- Budget Planner
- Dashboard
- Contact

## Project document

The project document is available here:
[2508049-isa-III.pdf](docs/2508049-isa-III.pdf).

## Local preview

This is a static HTML, CSS, and JavaScript site. Open `index.html` in a
browser, or serve the project directory with any static web server.

## Deployment

The site is deployed automatically to GitHub Pages by the workflow in
`.github/workflows/pages.yml` whenever changes are pushed to `main`.

FinWise is an educational student project and does not provide financial
advice or connect to real financial accounts.
